# Kodama

Атмосферная 2D-игра в стиле **Dark Atmospheric Pixel Art**.

Маленький дух Кодама просыпается под мёртвым деревом в лесу, который теряет магию и жизнь. Его задача: найти росток и отнести его в священное место, чтобы вернуть лесу жизнь.

## Сюжет

- Кодама находит росток и отправляется в путь.
- По дороге он проходит несколько локаций, решает головоломки и проходит лабиринт.
- В финале он сажает росток, и лес постепенно оживает.

## Движок

Godot Engine 4.7.2

## Управление

- Движение: `W, A, S, D`
- Взаимодействие: `E`

## Структура игры

1. Главное меню
2. Вступление (пробуждение Кодамы)
3. Первая локация (исследование леса)
4. Головоломки
5. Лабиринт
6. Финальная локация (посадка ростка)
7. Финал (возвращение жизни в лес)

## Команда

**Coca Cola**

## Ресурсы

Фоновые слои: набор **Forest&&Moon Pixel Art** (уточнить условия использования).
